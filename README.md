# NCAE 音效转换

Windows 原生 Rust 音效工具：查看本地 NCAE、生成/替换音效、解密导出、IR/JSON 预览。

> 仅处理你有权使用的文件。默认生成按钮会备份并替换所选音效，请确认目标。工具不绕过客户端完整性校验，也不保证所有播放器版本兼容。

## 直接运行

下载发行 ZIP 并完整解压，双击 **NCAE音效转换.exe**。
多格式实验支线使用 **NCAE音效转换-多格式支线.exe**；不要移除同目录的 runtime、converter 文件夹。
无需启动服务器、安装 Node 或全局配置 Python。要求 Windows x64 及正常的系统图形环境。

## 两个版本

| 版本 | 输入范围 | 运行依赖 |
|---|---|---|
| 原版 | WAV、RIFF/WAVE 封装的 IRS、参数 JSON | Rust 原生程序与随包运行库 |
| 多格式支线 | 原版 + FLAC、AIFF、AU、CAF、W64、RF64、ir.samples.v1 JSON/NPZ | 随包独立 Python/NumPy/SoundFile 后端 |

多格式代码位于独立工程，不会反向进入原版。

## 主要功能

- 自动定位网易云安装位置及音效目录；支持手动选择目录。
- 音效库搜索、类型色标、IR 优先排序。
- 仅预览左侧选中的 NCAE：IR 频响、JSON 模块页签与参数详情。
- 未知 PEQ 数字类型不猜测；EQ/PEQ 模型说明可从预览区信息提示查看。
- 默认备份后替换，成功后自动刷新列表与预览。
- 首次原备份保存在音效目录，形如 `原名称.original-特征码.bak`，后续不覆盖。
- 更多操作可解密导出、源文件转 WAV。导出完成显示保存路径。
- 跟随系统或手动亮暗主题、主题/悬停动画、可调高的日志区域。

## 保存规则

| 操作 | 保存位置与命名 |
|---|---|
| 正常替换 | 只修改目标并保留 .bak，不额外导出副本 |
| 解密导出 | Downloads，按音效库名称命名 |
| 源文件转 WAV | Downloads，沿用源文件名 |
| 取消直接替换，仅生成 | 程序目录 generated |

重名自动编号，避免覆盖已有导出。旧文件不会自动移动或删除。

## 开发与构建

```powershell
pwsh -File scripts/Build-Release.ps1 -Version 0.2.0
```

发布包由脚本从明确的文件清单生成，不包含个人音效、旧备份、替换记录或本机绝对路径。

## 验证

包含文件读写、备份恢复、导出命名、目录隔离、异步任务、预览核心数值对照、模块只读页签、主题及日志回归测试。
多格式后端另有跨格式转换验证；高精度浮点与整数格式互转可能量化，不宣称任意格式完全无损。
