# NCAE 音效转换 · 多格式版

[English](README.en.md) · [下载最新版](https://github.com/achievement18/NCAE-Audio-Converter/releases/latest) · [详细用法](docs/USAGE.md) · [格式说明](docs/FORMATS.md) · [来源与致谢](docs/ATTRIBUTION.md)

用于 **Windows x64** 的原生桌面音效工具，使用 Rust / egui / eframe。集中管理网易云音乐本地 `.ncae` 音效，查看 IR / JSON 预览，解密导出，并使用自己的脉冲响应或参数文件生成、备份和替换音效。

**正式发行只提供多格式版，一个 EXE 即可启动。** 无需自行安装 Python、Node.js 或启动网页服务。文档提供中英文；目前应用界面主要为中文，不代表已经提供英语 UI。

> **先备份，再替换。** 默认生成操作会备份并直接替换选中的音效。请确认目标，并只处理有权使用的文件。本项目不是网易云官方软件，不承诺任意客户端版本都能加载修改后的音效。

## 解密核心从哪里来？

NCAE 解密研究与算法实现来源于 **[AllenHeartcore/audioeffect-ncm](https://github.com/AllenHeartcore/audioeffect-ncm)**，重点参考其 [`ncae/decrypt.py`](https://github.com/AllenHeartcore/audioeffect-ncm/blob/b709cee76c6b4b0569a31c4345c3069aab831151/ncae/decrypt.py)。感谢原作者的逆向研究。

本项目不是从零独立发现 NCAE 解密算法：早期 Python 验证调用上游解密器，随后形成 Python 核心，再移植到 Rust；在此基础上增加反向封装、输入适配、备份恢复、桌面 GUI、可视化和独立运行时打包。上游 GUI 或完整音效系统并未直接搬入本项目。详细关系、修改说明与其他参考见 [来源与致谢](docs/ATTRIBUTION.md)。

本项目按 **GNU GPL v3.0** 分发，保留上游许可；第三方 MIT、Python、NumPy 等声明仍分别适用。见 [LICENSE](LICENSE) 与 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 下载与启动

1. 在 [Releases](https://github.com/achievement18/NCAE-Audio-Converter/releases) 下载 `NCAE-Audio-Converter-Multiformat-<版本>-windows-x64.exe`。
2. 将 EXE 放到自己可写的目录并运行。首次运行不要求联网下载安装依赖。
3. 程序会自动检测网易云安装位置与音效数据目录；没有找到时可手动指定。
4. 左侧选择一个音效，即可查看其类型和预览；需要替换时再导入源文件。

### “单 EXE”意味着什么？

下载和分发只需一个 EXE，不是 EXE 外加 `runtime` 文件夹。转换后端与依赖已经压缩内嵌。

第一次需要多格式转换时，后台会释放后端至：

```text
%LOCALAPPDATA%\NCAEAudioConverter\runtime\<版本-内容标识>\ready-…
```

后续启动会核对缓存内容并复用；发现改动或额外文件时会创建干净的新缓存。运行时仍会在磁盘产生缓存和转换临时文件，因此它不是“完全不落地运行”。缓存可在关闭程序后删除，下次转换会重新生成。请预留约 300 MB 可用空间用于缓存、临时文件与更新；较大的输入还需额外空间。

应用本身静态链接 C/C++ 运行库；内嵌 Python 所需的 DLL 随后端释放。Windows 系统 DLL、图形驱动和字体仍由操作系统提供。当前未提供 macOS、Linux 或 Windows ARM64 原生发行包。

## 功能一览

| 功能 | 作用与边界 |
|---|---|
| 自动定位音效目录 | 检测安装位置、用户数据目录及已知候选位置；支持手动目录与刷新。安装目录不一定就是音效目录。 |
| 音效库管理 | 名称搜索、IR / JSON / 未知类型徽标、默认 IR 优先排序、按名称排序；列表可调宽度。 |
| 目标提示 | 根据实际识别结果提示可用于 WAV 替换的卷积音效，不将未确认条目标记为已支持。 |
| 文件导入 | 文件选择、路径输入和拖入文件；读取格式、声道、采样率等可用信息。 |
| 多格式适配 | WAV、兼容的 IRS、FLAC、AIFF、AU、CAF、W64、RF64、采样 JSON / NPZ 转换为 NCAE 音频载荷。 |
| 参数音效 | 可导入适用的参数 JSON；与 `ir.samples.v1` 采样 JSON 分开处理。 |
| 长度处理 | 完整响应、匹配模板长度的最大能量窗口、从开头截取；短输入在等长模式下补零。 |
| 声道处理 | 保持输入声道、转单声道或双声道；不是通用环绕声混音器。 |
| 峰值对齐 | 在有可用 IR 模板时对齐其峰值；不是响度标准化或防削波限幅器。 |
| 备份与替换 | 默认保留首次原始 `.bak`，替换目标后自动刷新列表和预览。 |
| 恢复原音效 | 从可确认的备份恢复；损坏、歧义或缺失备份不会凭空重建。 |
| 解密导出 | 将选中 NCAE 中的 WAV、JSON 或未知二进制载荷导出，而不是直接渲染播放声音。 |
| 源文件转为 WAV 格式 | 当前输入转 WAV；未导入源文件时可使用选中的 IR 音效。参数 JSON 不能直接转成音频。 |
| IR 预览 | 所选音效的完整脉冲响应 FFT、声道切换、平滑和仅显示用归一化。 |
| JSON 预览 | EQ、PEQ、混响、旋转、音调、声场、压缩、限幅模块的只读图表或参数详情。 |
| 主题与交互 | 跟随系统亮暗主题、图标切换、主题过渡、悬停反馈；日志可折叠、拖高和滚动。 |
| 后台任务 | 扫描、转换与写入在后台执行，显示阶段和耗时，并防止重复冲突操作。 |

## 常用操作

### 用自己的 IR 替换音效

1. 在网易云中先下载并启用一个音效，再回到本程序刷新。
2. 从左侧选择已识别为 **IR** 的目标，检查名称和预览。
3. 导入自己的 WAV / IRS / FLAC 等文件。
4. 一般先使用“完整版”和“保持原声道”；按需要设置峰值对齐。
5. 保持“生成后直接替换目标音效”和“替换前备份原音效”开启，执行生成。
6. 完成后，在网易云切换到其他音效，再切回该音效。

### 只生成，不改原音效

取消“生成后直接替换目标音效”。新 NCAE 保存到 EXE 所在目录的 `generated` 文件夹。所选原音效不被替换；程序所在目录需要可写。

### 导出或转换 WAV

在“更多操作”选择解密导出或“源文件转为 WAV 格式”。完成弹窗给出实际保存路径；遇到同名文件会自动编号，不静默覆盖。

### 恢复

选中同一个目标音效，在“更多操作”中选择“恢复原音效”。恢复依赖有效备份；没有备份时不保证可恢复。详细操作见 [使用指南](docs/USAGE.md)。

## 文件保存规则

| 操作 | 位置 | 命名 / 行为 |
|---|---|---|
| 正常替换 | 原音效目录 | 修改目标；不额外导出到 Downloads |
| 首次备份 | 原音效旁边 | `原文件名.original-<特征码>.bak`，后续替换保留首份 |
| 仅生成 | EXE 旁的 `generated` | 生成新 NCAE，不改原文件 |
| 解密导出 | Windows Downloads 已知文件夹 | 使用音效库展示名称，根据载荷确定后缀 |
| 源文件转 WAV | Windows Downloads 已知文件夹 | 使用实际源文件名主体，重名添加序号 |
| 多格式运行时 | 用户本地缓存目录 | 从 EXE 按需释放，不是个人音效备份 |

若系统下载目录定位失败，程序会记录日志并使用回退输出目录；以完成提示中的实际路径为准。

## 格式支持与限制

- **音频输入**：`.wav` / `.wave`、`.irs`、`.flac`、`.aif` / `.aiff`、`.au` / `.snd`、`.caf`、`.w64`、`.rf64`。
- **采样数据**：采用 `ir.samples.v1` 结构的 `.json` / `.npz`。
- **参数数据**：适用于目标客户端的参数 JSON，不等同于音频采样数据。
- **GUI 输出**：生成 NCAE、解密导出载荷、源文件转 WAV。其他音频格式互转是源码中的后端 CLI 能力，不冒充 GUI 已有的下拉选项。
- IRS 支持的是可解析为音频的文件，尤其 RIFF/WAVE 封装；不是对所有同后缀私有格式的通用解密。
- 不自动重采样。生成 NCAE 音频采用 float32 WAV；float64 或高精度整数输入可能损失精度。
- FLAC 等容器的编码限制仍适用；不宣称所有格式任意互转都无损。
- 工具不能从任意 EQ、ViPER 预设或黑盒 DSP 参数中还原真实脉冲响应。

结构示例、声道语义与精度说明见 [格式说明](docs/FORMATS.md)。

## 预览不是音效编辑器

预览只跟随左侧所选音效，**不显示导入源文件的曲线**。点击模块是切换查看详情，不是开启/关闭真实效果。JSON EQ / PEQ 图为设置或可确认模型的参考，不代表混响、旋转等整套效果的实测响应；未知私有 PEQ 类型不会被猜测映射。完整限制可从界面 `i` 帮助与 [使用指南](docs/USAGE.md) 查看。

## 安全、隐私与兼容性

- 发行包与测试不携带用户音效、原始备份、账号信息或替换记录；测试数据为合成样本。
- 自动定位、转换、预览不需要登录网易云，也不要求上传音效文件。
- 修改的是本地文件；不会绕过客户端签名、完整性或云端校验。客户端可能拒绝、更新或覆盖这些修改。
- 使用外部导入文件前确认来源。大小、采样点和解压限制是防护措施，不是完整安全沙箱。
- 不要在两个程序实例中同时替换同一个文件。文件被占用时先停止相关操作，再重试。
- 可执行文件未作商业代码签名，Windows 可能显示信誉提示；请从本仓库下载并核对校验值，不要关闭全局安全防护。
