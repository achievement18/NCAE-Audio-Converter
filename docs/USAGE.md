# 使用指南

[English](USAGE.en.md) · [首页](../README.md)

## 1. 准备

只需正式发行的多格式 EXE。将它放在可写目录；不需要把源码 ZIP 解压到旁边。首次转换会自动释放内嵌后端到 `%LOCALAPPDATA%\NCAEAudioConverter\runtime`，任务期间保持程序开启。

本工具不提供内置音效素材、不播放试听，也不下载网易云音效。先在客户端中下载要操作的音效。

## 2. 找到并选择音效

程序分别检测客户端安装目录与音效数据目录，优先检查用户数据和已知位置。常见位置为 `%LOCALAPPDATA%\NetEase\CloudMusic\audioeffect`，但以实际检测为准。

找不到时使用手动目录；目录为空时先在网易云下载音效，再刷新。搜索按展示名称过滤；默认类型排序使 IR 靠前，也可切换名称排序。IR / JSON / 未知徽标表示实际识别结果，不保证客户端一定接受替换。

左侧边界可拖动调整宽度。展示名称可能去掉 `.ncae` 与生成的数字尾缀，不改变原文件名。

## 3. 导入源文件

使用“选择文件”、输入路径或拖入一个文件。完整列表见 [格式说明](FORMATS.md)。输入检查在后台执行，失败时查看具体错误，不要仅修改后缀冒充受支持格式。

参数 JSON 用来保存参数；`ir.samples.v1` JSON / NPZ 保存真实采样数据，二者不能互相混淆。预览区只显示左侧目标，不是刚导入的源文件。

## 4. 转换设置

| 设置 | 实际行为 |
|---|---|
| 完整版 | 保留完整输入响应，不裁掉尾部。 |
| 等长能量窗 | 用原 IR 模板帧数选择输入中能量最大的连续窗口；输入不足时补零。 |
| 仅保留开头 | 从输入起点取模板长度；不足时补零，过长时丢弃尾部。 |
| 保持原声道 | 保持输入声道，不是强制匹配目标声道。 |
| 单声道 | 对输入各声道取算术平均。 |
| 双声道 | 单声道复制为左右声道；超过两声道时只取前两声道，不执行环绕声混音矩阵。 |
| 峰值对齐 | 以可用目标 IR 的最大绝对采样值作缩放参考；不是 LUFS 响度对齐。 |

长度处理是裁剪或补零，不是采样率重采样。没有可用 WAV 模板时，模板相关长度和峰值处理不能提供同样效果。将音频塞入参数型目标不代表客户端必定接受，优先选已确认 IR 目标。

## 5. 生成与替换

默认开启直接替换与备份。执行前再次确认目标名称。后台显示当前任务阶段和耗时，不把未知进度伪造成百分比；忙碌时限制冲突操作。

替换时先保留首次原始文件到同目录 `.bak`，之后替换不会把已经修改的音效当作新原版覆盖备份。特征码用于区分内容，不是密码学签名。

替换成功后自动刷新列表和预览，保留选择。普通替换不在 Downloads 生成额外副本。客户端可能缓存音效；切到其他音效再切回来，必要时按客户端的正常流程重新加载。

关闭备份后会再次确认；没有其他有效备份时，恢复可能不再可行。不要同时开两个实例写同一个音效。

## 6. 仅生成与恢复

取消直接替换时，新 NCAE 写入 EXE 旁边的 `generated`；原音效不变。这里需要 EXE 所在目录可写。

恢复：选中原目标 → 更多操作 → 恢复原音效。优先使用相邻有效备份，历史替换记录仅作兼容回退。缺失、损坏或存在多个不能确定的备份时不会猜选。恢复后也会刷新列表与预览。

旧版本私人安装目录可能有 `replacement_records.json` 或 `legacy-backups`，它们不是发行内容，不应上传 issue、仓库或分享包。记录的备份丢失时，本工具不能重建真正原音效。

## 7. 两种导出

### 解密导出

导出左侧选中的 NCAE 载荷，WAV / JSON / 未知二进制分别使用对应后缀。文件主体名来自音效库展示名称。

### 源文件转为 WAV 格式

优先处理当前导入文件；未提供输入时，可使用所选的 IR 音效。实际源文件名主体用于输出名，保留点号、数字等有意义部分，不套用目标模板名称。

这个操作不应用生成区的裁剪、声道变化和峰值对齐；尽可能保留采样率、声道、帧数及可支持编码。编码兼容性与量化限制仍然存在。

两者默认保存到 Windows Downloads，重名自动编号；完成后统一弹窗显示路径。参数 JSON 不是可直接渲染的音频，不会虚构 WAV。后端或 CLI 手动指定路径的行为不等同于 GUI 防覆盖规则。

## 8. 看预览

- IR：完整响应 FFT、声道选择、平滑和仅预览归一化；静音不会伪装成 0 dB 平直频响。
- JSON：点击 EQ / PEQ / 混响 / 旋转 / 音调 / 声场 / 压缩 / 限幅切换详情；开关标志来自原文件。
- 页签不修改模块开关；关闭模块也能查看其保留参数。
- EQ / PEQ 模型不是整条 DSP 链的实测响应，未知私有类型不猜测。详细限制在 `i` 帮助中。
- 快速切换时，过期计算结果不能覆盖新选择。导入源文件不会成为另一个预览对象。

## 9. 主题与日志

默认跟随系统亮暗主题，图标按钮可手动切换，右键该按钮可恢复跟随系统。主题变化与按钮悬停有短过渡。

日志默认约五行、较小字号。可折叠、滚动或拖动顶部调整高度；同一次运行中收起再展开保留展开高度。不要把界面状态保留理解为所有设置都已跨进程永久保存。

## 10. 常见问题

| 问题 | 检查方法 |
|---|---|
| 列表空白 | 确认客户端已下载音效；重新检测或选择正确数据目录；清空搜索。 |
| 首次转换稍慢 | 正在释放约数十 MB 的后端；查看任务阶段和日志，等待完成。 |
| 缓存无法建立 | 检查 LOCALAPPDATA 权限、可用空间与路径是否被重定向为链接；不要全局关闭安全软件。 |
| 格式不支持 | 核对实际容器、编码和 JSON schema；私有 IRS、任意 EQ 预设不属于通用音频。 |
| 替换失败 | 检查文件权限、占用和目标是否被客户端更新；不要反复并发写入。 |
| 音效没有变化 | 客户端切换音效重新加载；确认目标、采样率和类型兼容；必要时恢复原版。 |
| 音量不合适 | 检查原样输入和峰值对齐；峰值匹配不等于听感一致。 |
| 找不到导出 | 看完成弹窗的实际路径与日志；可能使用已重定向 Downloads 或回退目录。 |
| 恢复失败 | 确认相邻首次备份仍在；软件不能补回已删除的原始数据。 |
| 单 EXE 运行后有文件夹 | 后端缓存按需释放属于设计行为，不需要提前携带该文件夹。 |

报告问题时附版本、操作步骤、脱敏日志和合成样本，不提交账号、个人音效或备份。
