# 使用说明

1. 从左侧选择本地音效。可按类型排序，IR 型优先。
2. 导入有权使用的 WAV/IRS 或适用的参数文件。
3. 确认目标和备份选项，再点击生成。默认直接替换，并保留首份 .bak。
4. 替换后会刷新列表和预览。播放器内可能需要切换到其他音效再切回。

正常替换不会在 Downloads 创建副本。需要文件时，从更多操作选择解密导出或源文件转 WAV。源文件转 WAV 保留源文件名；解密导出采用音效库名称；已有同名文件会加序号。

仅生成模式保存到 EXE 同目录 generated。预览页签、主题和归一化显示不会修改音效文件。

日志可展开、滚动及拖动上边缘调高。预览可收起；模块页签只用于查看详情。

本机旧记录迁移仅适用于个人安装目录。不要将 replacement_records.json、legacy-backups 或真实音效提交到仓库或发行 ZIP。
